Building LiDE50 Scan (cross-compiled on Ubuntu 24.04 with MinGW-w64)

  apt install g++-mingw-w64-x86-64-posix gcc-mingw-w64-x86-64-posix autoconf automake libtool
  git clone --recursive https://github.com/ifloofie/LiDE50-scanner.git && cd LiDE50-scanner
  # libusb 1.0.27 is a git submodule in third_party/libusb (official repository, tag v1.0.27)
  cd third_party/libusb && ./bootstrap.sh && \
    ./configure --host=x86_64-w64-mingw32 --enable-static --disable-shared --prefix=$PWD/../../deps && \
    make && make install && cd ../..
  make core app          # -> dist/LiDE50Scan.exe

Layout
  core/genesys   SANE 1.2.1 genesys backend, reduced to the GL841 / Canon LiDE 50 path
                 (other ASIC command sets removed, model table limited to 04A9:2213)
  core/shim      Windows replacements for sanei_usb (libusb/WinUSB), config and debug
  app/           Win32 user interface, scanner engine thread, image adjustments,
                 PDF/DOCX/PNG/JPEG/TIFF/BMP writers, one-time WinUSB binding
  third_party    miniz 3.0.2 (MIT), stb_image_write v1.16 (public domain),
                 libusb/ = submodule of github.com/libusb/libusb at v1.0.27 (LGPL)

Run "LiDE50Scan.exe --simulate" to exercise the complete driver code path against
the backend's virtual LiDE 50 (no hardware needed), and "--log" for a USB trace.

"--fake-usb" runs the real-hardware driver path against a fake GL841 chip
(core/shim/sanei_win.cpp). Its sensor follows the LED exposure registers like the
real one. Test settings (environment variables):
  LIDE50_FAKE_LED=<r>,<g>,<b>   brightness per exposure unit (default 24,24,24;
                                24,24,0 = dead blue LED; "flat" = ignore exposure)
  LIDE50_FAKE_AMBIENT=<n>       stray light added to every colour (50000 = lid open)
  LIDE50_FAKE_DATA=<0..255>     every byte constant (0 = no light at all)
  LIDE50_FAKE_FAIL_AT=<n>       the n-th bulk read fails (USB error)
  LIDE50_FAKE_AWAY=<n>          head reports "away from home" for n status reads
  LIDE50_TEST_PARK_MS=<ms>      imitate the head-return time
  LIDE50_CRASH_TEST=1           crash on purpose (tests the crash report)
